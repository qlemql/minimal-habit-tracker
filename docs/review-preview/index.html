무료

활성 습관 1개 · 모든 힌트 · 작은 실천 · 돌아보기 · 졸업 및 재시작. 기간 제한 없음.

Ssak Plus

무료는 습관 1개, Plus는 최대 3개 동시 진행 · 백업 및 복원.

스토어가 결제 처리

iOS는 App Store, Android는 Google Play. RevenueCat은 구매 권한 확인·복원을 담당.

시장 목표 가격안 결제 방식 운영 판단

모두 수요 검증 전 제안가이며 실시간 환산액·등록 완료 가격이 아닙니다. 제공되는 가격 포인트와 세금 표시를 각 콘솔에서 확인합니다. 언어·GPS가 아니라 스토어가 반환한 현지 가격을 표시합니다.

구매 → 확인 → 해제

스토어 가격 불러오기 → 결제창 → ssak_plus 권한 확인 → Plus 활성화. 취소·실패·대기 중이면 임의로 권한을 주지 않아요.

복원과 기기 변경

같은 스토어 계정에서는 구매 복원. 현재 계정 없는 구조에서는 iOS↔Android 구매 공유를 보장하지 않아요. 구매 복원과 습관 데이터 복원은 별개입니다.

수익을 보는 기준

미국 $7.99, 수수료 15%만 가정하면 약 $6.79. 세금·환불·SDK 비용·운영 시간을 제외한 순익이 아니에요. 지역별 실제 정산액으로 판단합니다.

출시 전 확인

각 스토어 상품·판매 지역·세금 및 정산 설정 → RevenueCat 연결 → 지역별 가격 표시 → 샌드박스 구매·취소·대기·재설치 복원·환불 검증. 지금 빌드에서는 구매 버튼이 비활성화되어 있어요.
