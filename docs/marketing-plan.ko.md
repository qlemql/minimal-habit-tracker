## 출시 상태와 홍보 조건

출시 작업은 [리뉴얼 후속 기록](renewal-native-followup.md), 기능과 무료 범위는 [스토어 문구](renewal-store-copy.md)를 따른다.

저장소의 10월 17일 인계 기록에는 iOS 메타데이터 수정 후 재제출, Google Play 계정 추가 정보 보완 후 심사 전송이 남아 있다. 현재 스토어 콘솔의 실시간 상태를 확인한 결과는 아니다. 공개 국가와 OS별 다운로드 가능 여부를 확인한 뒤 해당 지역에 설치를 요청한다. 먼저 공개된 플랫폼만 링크하고 다른 플랫폼은 출시 예정으로 안내할 수 있다.

현재 기능 설명:

- 습관 하나는 기간 제한 없이 무료.
- Plus는 일회성 구매로 최대 3개 습관을 함께 기록하고 백업·복원을 사용.
- 광고·구독·사용자 가입 없음.
- 기록은 기기에 저장되며 자동 기기 간 동기화는 제공하지 않음.
- 구매 처리 SDK가 있으므로 앱 계정이 없다는 이유로 데이터 수집·외부 서버 전송이 전혀 없다고 홍보하지 않음.

핵심 대상 가설은 독서·산책·일기 등을 시작했다가 바쁜 날 계획을 지키기 어려웠던 사람이다. 핵심 메시지는 평소 목표와 바쁜 날 목표를 미리 정하고 둘 다 기록할 수 있다는 점이다. 습관 형성 기간이나 성과는 보장하지 않는다.

## 계정과 연락처 관리

여러 Instagram 계정 생성·전환 자체는 Meta가 지원한다. 같은 번호로 몇 개까지 가입할 수 있는지는 이번 공식 자료에서 확인되지 않았으므로 번호당 5개 등의 한도를 확정하지 않는다. 같은 번호를 쓰면 계정이 완전히 독립적으로 취급되거나 추가 가입이 항상 승인된다고 보장하지 않는다. 개인 번호로 가입했다는 이유만으로 현재 싹 계정을 재생성할 필요는 없다.

운영 권고는 싹 전용 이메일 추가·인증, 계정별 고유 비밀번호, 인증 앱 기반 2단계 인증과 백업 코드 보관이다. 이메일과 복구 수단을 확보하기 전에 번호부터 제거하지 않는다. 설정 완료 여부는 아직 확인하지 않았다. 계정 보안 설정은 사용자가 직접 처리한다.

근거: [Meta의 다중 계정 안내](https://about.fb.com/news/2022/09/accounts-center-facebook-and-instagram/), [복구 연락처 안내](https://www.facebook.com/help/instagram/358911864194456), [인증 앱 권고](https://about.fb.com/news/2020/02/keeping-people-safe/).

## SNS 채널 선택 제안

초기 4주는 Instagram과 Threads를 운영 중심으로 두고, YouTube Shorts는 준비된 영상을 재활용하는 채널로만 추가한다. 지역별 계정을 동시에 개설하지 않는다. 별도 채널에 필요한 계정 생성·게시·문의 발송은 각 실행 요청에 따라 진행한다.

| 채널 | 초기 선택 | 역할과 실행량 | 확대 조건 |
|---|---|---|---|
| Instagram | 계속 운영 | 시각적인 공식 소개. 주 1개 신규 콘텐츠, 스토리는 여유 있을 때. 댓글 확인 포함 | 기존 게시물과 실제 앱 데모의 반응 비교 |
| Threads | 다음 신규 후보 1순위 | 만든 이유, 사용 사례, 질문 중심의 짧은 글 주 2개. Instagram 문구 복사에만 의존하지 않음 | 링크 방문·유의미한 답글·지역별 반응 확인 |
| YouTube Shorts | 다음 신규 후보 2순위 | 완성된 릴스의 워터마크 없는 원본을 월 2개 이내 재활용. 추가 영상 제작 의무 없음 | 제작 부담 대비 스토어 방문·설치가 나오는지 확인 |
| Reddit | 지속 운영 계정보다 커뮤니티 조사부터 | 영어권에서 규칙이 맞는 커뮤니티 2곳 조사. 홍보 허용 글·스레드에서 초기 사용자 모집 | 사용자 피드백과 유입이 생기는 커뮤니티에 집중 |
| X | 일본어 콘텐츠 반응 확인 뒤 시험 | 일본어 앱 데모와 사용 사례 중심의 소규모 운영 후보 | 일본어 소통 가능 시간 확보, 일본 유입 또는 문의 확인 |
| TikTok | 초기 보류 | 릴스·Shorts 제작과 게시가 안정된 뒤 기존 영상으로 시험 | Shorts 등에서 영상 메시지의 반응이 확인되고 운영 여력 확보 |
| Pinterest | 후순위 | 독서·기록 루틴과 연결되는 검색형 이미지 후보 | 랜딩 페이지와 검색용 콘텐츠가 준비된 뒤 |
| Facebook·LinkedIn | 별도 공식 계정 운영 보류 | 일상적으로 관리할 채널 수를 줄임. 관련 모임은 허용 규칙에 따라 별도 검토 | 실제 대상 사용자가 모이는 곳이라는 근거 확보 |

Threads의 링크 방문·지역 관련 인사이트는 운영 판단에 활용할 수 있다. Shorts 노출은 시청자 관심과 반응에 따라 달라지므로 새 계정의 도달이나 국가 노출을 보장하지 않는다. 이는 기능 근거를 바탕으로 한 채널 선택 제안이며, 특정 국가에서 가장 효과적인 SNS라는 시장 순위 주장과 다르다.

### 기존 채널 제안과의 관계

이전 대화의 Instagram + 영어 Reddit + 일본 X는 글로벌 확장 후보였다. 이번 계획은 운영 부담을 줄이기 위해 Threads와 영상 재활용부터 시험하고, Reddit은 커뮤니티 조사, X는 일본 실험 단계에 배치한다. 최종 채널 구성은 사용자와 확정한다.

## 언어와 지역 대응

Instagram은 현재 영어 게시물 2개로 시작했다. 이것만으로 지역 대응이 완료된 것은 아니다. 다음 제작 묶음은 같은 핵심 기능을 한국어·일본어·번체중국어로 소개하는 이미지 또는 짧은 영상이다. 한 게시물에 네 언어를 밀어 넣지 않고 언어별 버전을 구분한다. 기존 영어 게시물은 유지한다.

| 지역 | 언어와 표현 | 초기 유입 경로 제안 |
|---|---|---|
| 영어권 | 쉬운 영어, 영문 앱 화면 | Instagram, Shorts, 관련 Reddit 커뮤니티 |
| 한국 | 한국어 문구와 앱 화면 | Instagram, Threads, 독서·일기 모임, 국내 제품 소개 커뮤니티 후보 |
| 일본 | 일본어 앱 용어와 자연스러운 자막 | Instagram·Shorts부터 비교하고 X 추가 검토 |
| 대만 | 현재 앱의 대만 기준 번체중국어 | Instagram, Threads, 현지 독서·기록 관련 커뮤니티 후보 |
| 홍콩·마카오 | 번체중국어를 기반으로 현지 용어 검수. 영어 안내도 활용 | Instagram과 공통 랜딩에서 유입 확인 후 지역 소재 추가 |

홍콩·마카오까지 번체 글자만 바꾸면 현지화가 끝난 것으로 보지 않는다. 모든 국가에 매주 콘텐츠를 제작하겠다고 약속하지 않으며, 초기 4주 동안 각 언어의 기본 소개를 확보하고 반응이 있는 언어에 제작 시간을 더 배분한다. 중국 본토 캠페인은 이 계획의 대상에 포함하지 않는다.

국가별 별도 계정은 해당 언어 콘텐츠를 꾸준히 운영하고 댓글을 응대할 여력이 있으며, 반복적인 유입·문의가 생겼을 때 검토한다. 1개 게시물의 조회수만으로 계정을 분리하지 않는다. 게시 언어와 해시태그만으로 특정 국가 도달이 보장되지 않는다.

## SNS 외 홍보 선택 제안

### 스토어 검색과 소개 개선

출시 국가별 앱 이름·부제·설명·첫 스크린샷이 실제 사용 목적을 전달하도록 점검한다. 독서 기록, 바쁜 날 목표, 습관 하나 무료 같은 소재를 시험하되 검색량이나 경쟁 강도는 아직 검증하지 않은 가설로 둔다. 초기에 유입이 적으면 복잡한 A/B 테스트보다 한 번에 한 요소를 바꾸고 변경일과 유입을 기록한다.

유입이 쌓이면 스토어가 제공하는 등록정보 실험을 검토한다. 긍정적인 리뷰나 별점의 대가로 보상하지 않는다. 제품 사용자의 실제 불편과 후기 자체를 먼저 듣는다.

### 공통 랜딩 페이지와 검색 콘텐츠

기존 [랜딩 원본](landing/index.html)은 구버전 다크 디자인, 습관 3개 중심 설명, Expo 빌드 링크를 사용한다. 현재 홍보의 도착 페이지로 쓰기 전에 2.0 브랜드·무료 범위·공개 스토어 링크로 갱신해야 한다. 기존 [지원 페이지](index.html)도 옛 Three Habits 이름을 사용하므로 새 랜딩과 이름을 대조한다. 이번 기록 작업에서는 사이트를 수정하거나 배포하지 않았다.

새 페이지는 영어·한국어·일본어·번체중국어 선택, 실제 앱 화면, 무료와 Plus의 차이, OS별 다운로드 상태, 문의·정책 링크를 제공한다. 지역별로 아직 공개되지 않은 스토어 버튼은 설치 가능하다고 표시하지 않는다. 검색 유입용 글은 첫 달에 한 주제만 시작하고 페이지 언어를 차례로 확장한다. 예: 바쁜 날에도 가능한 독서 목표를 정하는 방법. 게시 직후 검색 순위나 방문을 보장하지 않는다.

초기에는 출시 알림 이메일 수집 시스템을 새로 만들기보다 공개 계정 팔로우와 문의 경로를 활용한다. 이메일 수집을 추가할 경우 목적·보관·동의 설계를 별도로 정한다.

### 초기 사용자 모집과 인터뷰

첫 모집 목표는 10~20명이다. 성과 예측이 아닌 작업 목표이며 네 언어 인원을 균등하게 채우는 조건은 아니다. 독서·일기 등 실제 습관을 기록하려는 사람을 대상으로, 다운로드 가능한 플랫폼에서 무료 습관 하나를 7일간 써보도록 제안한다. 출시 전이라면 정상 제공 가능한 테스트 배포 방식이 확보된 경우에만 모집한다.

질문은 세 가지로 제한한다. 첫 습관을 만들 수 있었는지, 평소 목표와 바쁜 날 목표를 구분했는지, 다시 앱을 열거나 그만둔 이유가 무엇인지 묻는다. 후기는 동의한 범위에서만 공개하고, 일별 개인 기록을 자동 수집한다고 가정하지 않는다. 동의한 사용자의 7일 후 답변을 전체 D7 유지율로 표기하지 않는다. 버그·UX·기능 피드백은 [피드백 로그](feedback-log.md)에 기록한다.

### 관심사 커뮤니티

영어 Reddit, 국내 독서·일기 모임과 제품 소개 커뮤니티, 일본·번체중국어권의 관련 모임을 후보로 조사한다. 구체적인 커뮤니티의 홍보 허용 여부는 게시 직전에 확인한다. 개발자임을 밝히고, 실제 사용 사례와 피드백 요청을 중심으로 작성한다. 같은 링크를 여러 곳에 반복해서 뿌리지 않는다. 커뮤니티별 규칙은 Reddit의 공통 스팸 규칙과 별도로 적용된다. [Reddit 공식 안내](https://support.reddithelp.com/hc/en-us/articles/360043504051-Spam)

국내 디스콰이엇은 제품 피드백 후보로 검토하되 현재 등록 규칙은 확인 전이다. 개발자 반응과 일반 사용자의 지속 사용을 같은 지표로 보지 않는다.

### 크리에이터와 뉴스레터

정식 공개와 실제 앱 데모를 확보한 뒤 독서·일기·문구·루틴 관련 크리에이터 또는 앱 소개 뉴스레터 5곳을 조사한다. 팔로워 규모보다 콘텐츠 적합성·언어·평소 앱 소개 방식을 본다. 소개자료는 한 장 요약, 15초 데모, 실제 기능·무료 범위, 공개 다운로드 링크, 문의처로 구성한다.

첫 달은 후보와 개별 제안문 준비까지 한다. 이메일·DM 발송과 유료 협업 계약은 사용자의 명시적 실행 요청 및 예산 확정 뒤 진행한다. 특정 리뷰나 긍정 평가를 조건으로 요구하지 않는다.

### 출시 이벤트와 스토어 추천 신청

Product Hunt는 실제 사용 가능한 앱과 공통 소개 페이지가 준비된 뒤 한 번의 출시 이벤트 후보로 둔다. 순위보다 방문·설치·피드백을 기록한다. 출시 당일 이후에도 사용자 문의를 받을 시간이 필요하다. [공식 출시 가이드](https://help.producthunt.com/en/articles/17350772-launch-guide)

Apple의 Featuring Nominations로 출시 또는 업데이트를 소개할 수 있다. 소개 문구·화면·출시 정보를 준비한 뒤 제출 여부를 정하며, 신청이 선정 보장은 아니다. [Apple 추천 신청 안내](https://developer.apple.com/app-store/getting-featured/)

오프라인은 사용자가 이미 참여하는 독서 모임 등에 시연하는 경우부터 고려한다. QR 인쇄물이나 행사 비용은 초기 필수 항목으로 잡지 않는다. 직접 참석할 수 없는 해외 시장에 오프라인 실행량을 배정하지 않는다.

### 유료 광고

현재 집행 예산은 확정하지 않았으며 기본 제안은 0원이다. 스토어 공개, 다운로드 경로와 유입 측정, 실제 사용 피드백이 마련된 뒤 한 국가·한 언어·한 채널의 제한된 실험을 설계한다. 예산 상한을 별도로 정하고, 조회수만으로 광고를 늘리지 않는다. Plus 가격·구매 전환·사용 유지 데이터를 모르는 상태에서 수익성이나 적정 설치당 비용을 확정하지 않는다.

## 초기 4주 실행안

주차는 오늘 기준의 확정 출시일이 아니라 실행 시작 시점부터 계산한다. 스토어 공개가 늦어지면 모집·설치·출시 이벤트를 뒤로 옮긴다. 그동안 언어 소재와 랜딩을 준비한다.

## 측정과 다음 결정

조회수, 프로필 방문, 링크 방문, 스토어 방문, 설치, 사용 피드백을 각각 기록한다. SNS 링크 클릭을 설치로 간주하지 않고, 링크 방문자를 개인정보나 설치 사용자와 임의로 연결하지 않는다.

Apple은 App Store Connect의 캠페인 링크를 활용하고, Google Play는 지원되는 UTM 및 획득 보고서로 비교한다. 보고서 집계 기준과 최소 표시 조건 때문에 작은 초기 캠페인의 값이 보이지 않을 수 있다. 데이터가 없는 칸은 0이 아니라 미집계·미확인으로 적는다. 방문→설치 전환율은 같은 기간과 보고서 정의의 분모·분자를 사용할 수 있을 때만 계산한다.

근거: [Apple 캠페인 링크](https://developer.apple.com/help/app-store-connect-analytics/acquisition/campaign-links), [Google Play 획득 보고서](https://support.google.com/googleplay/android-developer/answer/6263332?hl=en).

채널·언어·콘텐츠마다 캠페인 이름을 구분한다. 예: `instagram_en_busyday_202610`, `threads_ko_intro_202610`. 실제 공개 링크가 확정되면 스토어별 지원 방식으로 생성한다. 현재 페이지에 임의 토큰을 넣은 링크는 배포하지 않는다.
