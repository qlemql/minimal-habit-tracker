## 링크 준비와 적용안

[채널별 링크 JSON](global-channel-links.json). Apple 링크는 실제 생성, Android/랜딩 URL은 공식 파라미터 설명에 따른 준비안이다. 공개 배포·전체 경로 검증·집계 발생은 아직 아니다.

최소 적용안: 랜딩 생성기에서 허용한 utm_source 4종과 campaign `first_record_202611`만 읽고 각 OS 버튼에 해당 Apple 캠페인/Google UTM을 전달한다. 기타 입력은 무시하고 기본 링크 유지. 쿠키·로컬 저장·기기 지문·외부 분석 SDK 없이 링크만 구성하고 언어 이동 시 같은 허용 값만 유지한다. 미리보기에서 4채널×2스토어와 파라미터 없는 기본 링크, 잘못된 입력, 언어 전환을 검증한 뒤 배포 상태를 별도로 기록한다. 현재 구현·배포하지 않았다. 코드 권한·개인정보 문구 정합성 확인도 해당 구현 작업에서 처리한다.

Apple은 생성 화면에서 서로 다른 Apple 계정 5개 이상 설치 후 캠페인이 표시된다고 안내했다. 캠페인 표는 데이터 부족. [Apple 공식 안내](https://developer.apple.com/help/app-store-connect-analytics/acquisition/campaign-links/).

Google은 UTM source/campaign 차원과 설치 버튼 클릭 지표를 제공하며 실제 획득과 구별한다. [Google 공식 안내](https://support.google.com/googleplay/android-developer/answer/9859173?hl=en). UTM 주소 생성만으로 실제 설치 귀속이나 랜딩 클릭 수집이 완료됐다고 판단하지 않는다.
