# 싹 SNS 마케팅 정책

시행: 2026-10-22. 사용자가 승인한 지속 운영 기준. Instagram @ssak.app과 X @Ssakhabit의 콘텐츠 기획·제작·댓글에 적용한다. 실행 현황은 [운영 계획](marketing-plan.ko.md), 국가별 참고 자료는 [플레이북](marketing-playbook.ko.md), 체크와 지표는 [운영 보드](marketing-a-z.html)에 기록한다. 과거 실행 기록과 제안이 충돌하면 콘텐츠 방향은 이 정책을 따른다. 플랫폼 규정과 출시·가격 정보는 실행 시 최신 상태를 확인한다.

## 1. 계정의 목적과 중심 메시지

생활에 맞지 않았던 습관을 다시 시도하려는 사람에게 싹을 알린다. 우선 영어권에서 독서·글쓰기·정리·스트레칭 같은 구체적인 생활 상황을 다룬다. 해외 전체를 한 성격으로 가정하지 않는다.

중심 메시지는 **평소 계획과 바쁜 날의 작은 대안을 미리 정하고, 실제로 한 만큼 기록한다**이다. 주간 계획은 하루 쉬어도 사라지지 않는다. 기존의 부담 없는 분위기와 이 제품 설명을 연결한다.

조회와 팔로워는 발견의 지표다. 프로필 방문·링크 클릭·스토어 방문·다운로드·실제 피드백을 구분해 본다. 공감 반응만으로 앱 수요나 습관 형성 효과를 확정하지 않는다.

## 2. 공통 인격과 말투

기존 ‘싹 인격 v0.1’을 이어간다. **작은 실천과 재시작에 관심이 많은, 편하고 담백한 관찰자.** 일상의 어긋남을 알아보고 짧게 웃을 수 있는 앱 계정이다.

- 짧고 구체적으로 말한다. 매번 위로·칭찬·교훈·질문을 한 세트로 붙이지 않는다.
- 유머는 준비에 빠지거나 시간이 사라지는 상황을 향한다. 조금 한 행동이나 쉬는 사람을 조롱하지 않는다.
- 캐릭터의 허구 상황은 자유롭게 만들되 운영자·실제 사용자의 경험이나 성과로 바꾸어 말하지 않는다.
- 슬랭·이모지·소문자 말투는 문맥에 맞을 때 쓴다. 다른 계정의 인격이나 친밀감을 복제하지 않는다.
- 댓글 전에는 원문과 앞뒤 대화를 읽는다. 한 지점에 자연스럽게 반응하고, 실제로 궁금한 경우에만 질문한다. 할 말이 없으면 지나간다.
- 대화 대상은 계정 분야보다 실제 생활 상황으로 고른다. 독서·글쓰기·운동·정리 등에서 재시작, 시간 부족, 작은 실천을 이야기하는 글을 찾는다. 당일 콘텐츠가 독서라는 이유로 독서 계정에만 한정하지 않는다. 분야별 고정 할당량은 두지 않는다.
- 응답이 오면 앞 대화를 이어간다. 관계없는 대화를 앱 홍보로 돌리지 않는다.

## 3. 캐릭터의 시각적 연속성

기존 밈의 헝클어진 머리·넉넉한 크림색 티셔츠 캐릭터와 따뜻한 일러스트 화풍을 이어간다. 새 이미지를 만들 때 기존 원본과 프롬프트를 읽고 참조 이미지로 사용한다. 세부 외형은 원본을 기준으로 맞추며 임의로 새 마스코트나 인격을 만들지 않는다.

- [글쓰기 밈 원본](marketing-assets/x-meme-persona-2026-10-21/300-words-vs-title.png) · [프롬프트](marketing-assets/x-meme-persona-2026-10-21/image-prompt.txt)
- [정리 밈 원본](marketing-assets/x-meme-persona-2026-10-20/playlist-vs-one-sock.png) · [프롬프트](marketing-assets/x-meme-persona-2026-10-20/image-prompt.txt)
- 브랜드 로고·색상은 [브랜딩 가이드의 현재 적용 절](branding-guide.md)을 따른다.

밈은 독립적으로 웃겨도 된다. 매번 앱 화면·로고·설치 요청·교훈을 얹지 않는다. 제품 사용을 설명할 때는 실제 데모로 이어지는 별도 콘텐츠나 문맥에 맞는 본문을 사용한다. 이미지의 작은 행동을 실패로 취급하지 않는다.

## 4. 콘텐츠 형식을 적용하는 방법

다른 분야의 성공 콘텐츠에서 시점·대비·전개·공개 순서를 배운다. 문장·캐릭터·영상·디자인을 복제하지 않는다. 성공 형식은 시험할 가설이며 싹의 타깃에서도 성공한다는 증거는 아니다.

| 형식 | 싹 적용 | 인격과 제품의 연결 |
|---|---|---|
| 생활 상황 POV | 읽으려 했는데 이미 밤 11시 48분인 장면 | 피곤한 상황을 알아보고, 한 페이지라는 대안을 실제 데모에서 보여준다. |
| 평소 날과 바쁜 날의 대비 | 스트레칭 10분 / 1분, 글 300단어 / 한 문장 | 두 선택 모두 기록되는 기능을 보여준다. |
| 기대와 현실의 두 컷 밈 | 글을 쓰려다 제목 서체만 고르는 기존 캐릭터 | 짧은 농담으로 끝내도 된다. 앱 설명은 다른 콘텐츠에서 이어간다. |
| 주간 흐름 시연 | 수요일에 쉬고 다른 날에 기록해 주간 계획 채우기 | 완벽한 매일 기록보다 생활에 맞는 계획을 화면으로 설명한다. |

우선은 평소 날과 바쁜 날의 대비를 중심 데모로 삼고, 기존 캐릭터 밈과 POV를 함께 시험한다. 티어리스트 등 다른 형식은 타깃에 유용할 때만 추가한다. 어떤 습관·사람이 더 우월하다는 순위를 억지로 만들지 않는다.

## 5. 후킹과 내용의 약속

릴스 첫 화면에서 대상의 상황이나 두 선택의 차이를 이해하게 한다. 첫 1~3초는 제작 목표이며 성과를 보장하는 알고리즘 규칙이 아니다. 소리 없이도 핵심을 이해할 수 있게 한다.

- 공감: 늦어진 저녁, 준비만 하다 지난 시간 등 구체적인 장면.
- 대비: 평소 10분과 바쁜 날 1분을 바로 보여주기.
- 관점 전환: 작은 대안도 미리 계획할 수 있다는 제품의 선택을 보여주기.
- 결과·실험형: 실제로 기록한 실험이나 화면으로 입증할 수 있을 때 사용하기.

도입에서 예고한 내용은 본문에서 보여준다. 근거 없는 통계, 가짜 전후 성과, ‘이것만 하면 성공’, 불안을 과장한 경고는 사용하지 않는다. 26가지 패턴을 모두 써야 할 필요는 없다.

제작용 문구 후보이며 아직 게시하지 않은 예:

- `You planned to read. Then the evening happened.` → 바쁜 날 한 페이지 선택과 실제 기록 화면.
- `Ten minutes when you can. One when you can’t.` → 평소/바쁜 날 스트레칭 비교.
- 기존 `the title is thriving.` → 글쓰기 캐릭터 밈의 짧고 건조한 말투 기준.

## 6. 채널별 사용

| 채널 | 기본 운영 |
|---|---|
| Instagram @ssak.app | 앞으로 영어 중심. 릴스·캐러셀에서 장면과 화면으로 전달하고, 캐릭터 밈은 한 장으로도 사용한다. 캡션 길이는 내용에 맞춘다. |
| X @Ssakhabit | 짧은 생활 관찰·캐릭터 농담·대화에 맞는 답글. 앱 데모에는 필요한 설명을 붙이고, 밈은 문맥이 맞으면 답글로 연결하거나 단독 게시한다. |

2026-10-24 운영 확인: 기존 X·Instagram은 영어 중심으로 유지한다. 일본어·번체 홍보글을 기존 계정에 추가하지 않는다. 일본어 X 글1편은 사용자 삭제 완료 보고를 기록했고, 해외 현지 접근은 현지어 랜딩과 허용된 외부 소개 경로부터 검증한다.

같은 인격과 소재를 유지하되 채널별로 편집한다. 모든 게시물을 앱 광고로 끝내지 않는다. 제품 소개에는 설치 경로를 쉽게 찾게 하고, 밈의 도달을 다운로드로 해석하지 않는다. 기존 채널에 집중하며 이 정책이 새 채널 개설이나 자동 게시 일정을 뜻하지 않는다.

## 7. 제작과 검토 절차

매번 제작하기 전에 이 문서, 운영 계획의 최신 기록, 최근 SNS 게시물·대화를 확인한다. 기존 인격·캐릭터·같은 소재의 게시 이력을 함께 읽는다.

1. 대상과 상황 한 가지를 정한다. 예: 자기 전 읽으려다 피곤해진 사람.
2. 무엇을 보여줄지 정한다. 공감 장면 / 작은 대안 선택 / 실제 기록 중 핵심 하나.
3. 형식과 도입을 선택하고 인격에 맞는 짧은 문구를 만든다.
4. 이미지에는 기존 캐릭터 원본을 참조하고, 기능 설명에는 실제 앱 화면을 쓴다. 웹 데모·예시 데이터라면 정확히 표시한다. 그림 속 UI와 실제 UI를 구분한다.
5. 도입의 약속, 말투, 기능 사실, 자막 가독성, 캐릭터 연속성, 대체 텍스트를 검토한다. AI 이미지 표시는 해당 채널의 현재 요구에 맞춘다.
6. 소재·타깃·형식·도입·원본·문구·상태를 제작 폴더에 남긴다. 준비/게시/성과 확인을 구별한다.
7. 게시가 요청된 작업에서는 결과 링크와 확인 증거를 운영 계획에 기록한다. 정책 저장 자체를 SNS 게시 완료로 기록하지 않는다.

## 8. 첫 실험과 평가

첫 묶음은 독서를 같은 소재로 두고 **POV / 평소와 바쁜 날 비교 / 캐릭터 밈**을 한 편씩 준비하는 계획이다. 현재 운영에 더하는 실험 가설이며 실제 제작·게시 상태는 아래 실행 기록을 따른다. 첫 세 편은 반응을 탐색하는 용도이고 성공·실패를 확정할 표본으로 쓰지 않는다.

2026-10-23 추가 실행: 사용자 승인으로 독서 타깃의 2주 릴스4편 실험과 초기 사용자3명 모집을 시작했다. 릴스1편과 X 모집글·데모 답글, Reddit의 허용된 월간 App Shelf 소개를 게시했다. 릴스3편은 준비 완료·미게시이며 예약하지 않았다. 같은 타깃의 서로 다른 형식 탐색으로, 반응을 보고 다음 편을 수정한다. 외부 팔로워는 두 채널 모두0으로 기록한다. Instagram 표시1명은 사용자 본인이다. 정확한 게시·측정 상태는 운영 계획 최신 기록을 따른다.

2026-10-22 실행: POV와 기존 캐릭터의 두 컷 밈을 결합한 독서 1편을 Instagram과 X에 게시했다. X에는 평소/바쁜 날 계획을 설명하는 텍스트 부모 글도 게시했다. 이 텍스트는 비교 데모로 집계하지 않는다. 최초 계획의 나머지 비교 데모·별도 형식은 미제작이며, 상세는 운영 계획의 최신 실행 기록을 따른다.

각 편에 주된 목적을 기록한다. 밈은 공감·공유·프로필 관심, 데모는 기능 이해·스토어 관심을 중심으로 살핀다. 가능하면 게시 후 24시간과 7일에 같은 경과 시간으로 비교하되 노출이 적으면 판단을 보류한다. 이후에는 한 번에 소재·형식·도입을 전부 바꾸지 말고, 유망한 방향에서 하나씩 바꾼다. 첫 세 편은 형식이 다른 탐색이므로 엄밀한 A/B 실험으로 부르지 않는다.

기록 항목: 날짜·채널·링크·타깃·소재·형식·도입·경과 시간·도달/조회·시청 유지(제공될 때)·공유/저장·프로필 방문·링크/스토어 유입·다운로드·실제 답변. 미제공·미확인은 0과 구별한다. 직접 연결 근거가 없는 설치를 특정 게시물 덕분으로 집계하지 않는다.

주간 검토에서 유지할 형식과 다음 변경 한 가지를 결정해 운영 계획에 남긴다. 표본이 적으면 콘텐츠 방향을 성급하게 갈아엎지 않는다. 제작 부담은 기존 주 2~3시간·유료 집행 0원 운영 가정 안에서 조절하며 게시 비율이나 매일 게시를 의무화하지 않는다.
