# 싹 X와 Instagram 4주 마케팅 실행 계획

작성일: 2026년 11월 7일. 실행 기간: 11월 8일 일요일부터 12월 5일 토요일까지, 한국시간 기준.

바쁜 날에도 독서로 돌아오는 방법을 보여주는 계정으로 운영한다. X에서는 개발자의 구체적인 생각과 독서 대화를 쌓고, Instagram에서는 생활 장면과 실제 기록 과정을 반복 가능한 시리즈로 만든다. 매일 오후 9시에 시작 알림을 받고 하루 30분을 기본으로 실행한다. 영상 제작일은 최대 60분, 바쁜 날은 10분으로 줄인다.

## 목표와 현재 기준

운영 목표는 주 6일 이상 실행 기록, X 주 3개, Instagram 주 3개(릴스 2개와 캐러셀 1개)다. 반응이 있는 대화를 우선하며 댓글 수를 채우려고 쓰지 않는다. 첫 사용 확인 3명과 구체적인 의견 3건을 4주 성과 목표로 둔다. 예상 실적이나 보장 수치가 아니다.

기존 독서 실험의 11월 19일 목표는 중간 점검으로 유지한다. 미달이면 원인과 수치를 기록하고, 12월 5일 최종 점검까지 개선한다. 기존 마감일을 달성한 것으로 바꾸지 않는다.

| --- | --- | --- |
| X 팔로워 | 11월 6일 0명 | 11월 8일 시작 전에 재확인 |

## 매일 실행 순서

- [ ] 최신 운영 기록과 오늘 날짜를 확인한다. 이미 게시된 항목과 미완료 항목을 구분한다.
- [ ] 5분: X와 Instagram의 새 사람 답변을 확인한다. 기존 대화의 후속 답변이 우선이다.
- [ ] 10분: 독서 재시작·바쁜 날의 습관에 관한 글을 읽는다. 내용에 기여할 말이 있을 때만 두 채널 합계 1~3건 대화한다. 맥락 없는 앱 링크·복사 댓글은 쓰지 않는다.
- [ ] 10분: 요일별 게시 또는 다음 콘텐츠 제작을 진행한다.
- [ ] 5분: 실제 게시 주소, 관찰 시각, 수치, 남은 작업을 저장한다. 첫 사용 여부는 상대의 명시적인 확인이 있어야 집계한다.

바쁜 날의 최소 실행은 새 답변 확인, 진행 중 대화 1건 대응 또는 다음 콘텐츠 한 문장 작성, 상태 기록이다. 결석분을 다음 날 두 배로 게시하지 않는다. 업로드나 로그인이 막히면 완성된 초안과 정확한 파일 경로를 남기고, 사용자 조작이 필요한 한 단계만 요청한다.

## 매주 반복할 일정

| 요일 | 주요 작업 | 산출물 |
| --- | --- | --- |
| 일요일 | 전주 회고, 다음 주 소재 확정, 촬영을 한 번에 준비 | 소재 3개와 촬영 목록; 1주차는 기준값·프로필 점검 |
| 월요일 | 평소 목표를 못 채우는 생활 장면 | Instagram 릴스 A, 같은 주제의 독립적인 X 글 |
| 화요일 | 독서 대화, 일본 기존 채널 확인 | 대화 기록, 새 댓글 대응; 무조건 새 홍보 글을 쓰지는 않음 |
| 수요일 | 실제 행동과 개발자의 선택을 설명 | Instagram 캐러셀, X 개발자 관점 글 |
| 목요일 | 동의한 체험자의 첫 기록 확인, 협업 후보 검토 | 구체적인 의견 또는 후보 1곳의 적합성 기록 |
| 금요일 | 바쁜 날 대안을 실행하고 기록하는 장면 | Instagram 릴스 B, X 실험·배운 점 글 |
| 토요일 | 그 주 수치 비교, 다음 주 바꿀 요소 하나 선정 | 주간 회고; 국내 채널과 스토어는 필요할 때만 추가 점검 |

실제 제작이 60분을 넘으면 게시일을 옮기고 기록한다. 주간 목표보다 내용의 정확성과 대화 품질을 우선한다. 오후 9시는 운영 시작 시간이며 최적 게시 시간으로 검증된 값이 아니다.

## 첫 주에 바로 사용할 소재

| 날짜 | 할 일과 소재 |
| --- | --- |
| 11월 8일 일 | X·Instagram 프로필과 기준값 점검. 운영자가 개발자임을 소개에 드러내고 독서 대상·양 스토어 접근 경로 확인. 기존 고정 X 글은 iOS만 안내하므로 최신 소개를 준비. 새 계정 생성 없이 기존 계정 활용. 월·금 영상에 필요한 책·손·기록 화면 준비 |
| 11월 9일 월 | 릴스 A: “Too tired for ten minutes? Read one page.” 책을 펼침 → 한 페이지 읽음 → 실제 완료한 작은 대안 기록. X는 목표를 줄이는 이유를 구체적으로 설명 |
| 11월 10일 화 | 영어 독서 대화와 일본 Reddit·Tsukutta 기존 반응 확인. 11월 9일 콘텐츠는 실제 게시 시각에서 24시간이 지난 뒤 관찰 |
| 11월 11일 수 | 4장 캐러셀: “A smaller reading plan for busy days” → 평소 10분 → 바쁜 날 1페이지 → 실제 한 행동을 기록. X는 작은 대안을 미리 정하도록 만든 설계 이유 |
| 11월 12일 목 | 11월 5일 게시물 7일 경과 측정. 소규모 독서 계정 후보 1곳을 최근 게시물·독자층·실제 대화 기준으로 검토. 협업 제안문까지 준비 |
| 11월 13일 금 | 릴스 B: “Three days away. Start at your bookmark.” 쉬었던 상황을 예시로 표시하고 돌아오는 행동을 보여줌. X는 이번 주 관찰과 아직 모르는 점 공유 |
| 11월 14일 토 | 1주차 회고. 도입 문구·장면·대상 중 다음 주 바꿀 요소 하나 선정. 저조회만으로 계정 전체를 실패 판정하지 않음 |

영상은 10~20초를 제작 기준으로 삼는다. 얼굴 출연은 필요 없으며 책·손·앱 화면으로 만들 수 있다. 실제로 하지 않은 독서 경험을 개발자의 경험으로 주장하지 않는다. 기존 웹 데모를 활용하면 웹 빌드·샘플 데이터·모바일 차이를 표시한다. 새 원본 촬영이 없으면 생활 장면을 촬영했다고 말하지 않는다.

## 4주간 바꿀 범위

| 기간 | 초점 | 주간 판단 |
| --- | --- | --- |
| 11월 8~14일 | 대상·프로필·기본 시리즈 정리 | 어떤 게시물과 대화가 프로필 방문이나 구체적 답변으로 이어졌는지 |
| 11월 15~21일 | 같은 형식에서 첫 문장 또는 첫 장면 하나 변경 | 11월 19일 기존 첫 사용 목표 중간 점검 포함 |
| 11월 22~28일 | 실제 질문을 콘텐츠에 반영, 적합한 협업 후보 3곳까지 검토 | 관심을 보인 상대와만 다음 단계; 협업 성사 수를 미리 약속하지 않음 |
| 11월 29일~12월 5일 | 의미 있는 반응을 만든 주제 재시험 | 4주 결과를 바탕으로 지속·수정·축소 결정 |

영어 X·Instagram이 주력이다. 일본어는 화·목에 기존 Reddit·Tsukutta 반응과 일본어 독서 랜딩을 유지한다. 한 게시물에 영어·일본어를 섞지 않는다. 국내 채널은 주간 점검과 실제 소식이 있을 때 활용한다. 대만 Mobile01은 상업 홍보 허용 근거가 확인될 때까지 보류한다.

## 대화와 협업 기준

일반 대화에서는 게시자의 질문이나 경험에 직접 답한다. 실제 관심을 보였을 때 개발자임을 밝히고 무료 습관 1개 체험을 제안한다. 첫 기록이 가능한지, 어느 단계가 헷갈렸는지만 묻는다. 구매·스토어 리뷰·개인 독서 기록을 요구하지 않는다. 답변 없는 사람에게 반복해서 권하지 않는다.

협업 후보는 팔로워 수보다 독서 주제 적합성, 최근 게시의 지속성, 댓글 대화의 구체성을 본다. 후보 발굴과 맞춤 초안 작성까지 진행하고, 개인 DM·메일 발송과 유료 계약은 별도 사용자 지시에 따른다. 협찬이나 연출을 실제 이용 후기처럼 꾸미지 않는다.

## 측정과 기록

각 게시물은 실제 게시 시각 기준 24시간과 7일에 확인한다. 확인 시각이 다르면 경과 시간과 누적값이라고 명시한다. 숫자가 보이지 않으면 미확인으로 남기며 0으로 대체하지 않는다.

기록 위치는 docs/marketing-assets/daily-YYYY-MM-DD/status.json과 docs/marketing-plan.ko.md다. 매일 최소한 다음을 남긴다.

- 작업 상태: 예정, 초안, 사용자 조작 대기, 게시 확인, 보류 중 하나
- 게시 URL, 본문, 언어, 게시 시각, 증빙 경로
- 조회·도달·프로필 방문·팔로워 변화·저장·공유 중 실제 확인 가능한 수치
- 새 사람 답변, 체험 의사, 첫 기록 완료, 구체적인 의견을 각각 구분
- 다음 작업 1개와 필요한 사용자 조작

공개 랜딩의 방문·클릭 수집은 아직 구현되지 않았고 앱 운영 이벤트 수신도 검증되지 않았다. 플랫폼에서 보이지 않는 전환율은 계산하지 않는다. 필요하면 실제 수집 상태를 별도 점검한다.

| 관찰 결과 | 다음 조치 |
| --- | --- |
| 계속 노출이 작음 | 추천 자격·공개 상태 등 확인 후 도입 장면과 주제를 하나씩 변경 |
| 노출은 있으나 프로필 방문·팔로우가 없음 | 팔로우할 이유, 소개, 콘텐츠의 연속성을 개선 |
| 방문·체험 의사는 있으나 첫 기록 확인이 없음 | 스토어 설명과 첫 설정 과정 점검; 무응답을 설치 실패로 단정하지 않음 |
| 첫 기록과 구체적 피드백이 생김 | 해당 경로·주제를 반복하고 동의한 후속 질문으로 확인 |

1주차는 운영 가능성과 초기 신호, 4주차는 지속 여부를 판단한다. 바이럴 1개나 작은 표본으로 형식의 우열을 확정하지 않는다. 팔로워 구매·무차별 팔로우·자동 대량 댓글은 사용하지 않는다.

## 역할과 재개 방법

Codex는 기록을 읽고 오늘 작업을 선정하며 초안·편집·공개 반응 점검·게시 확인·운영 기록을 진행한다. 사용자는 필요한 로그인, 파일 선택, 실제 촬영 자료 제공을 맡는다. 매일 알림은 오늘 체크리스트를 알려주는 용도이며 자동으로 외부 게시물을 발행하는 예약이 아니다.

이 채팅에서 “오늘 마케팅 진행해줘”라고 하면 이 계획과 최신 운영 기록부터 읽고 이어간다. 커밋·푸시는 별도 요청 시 수행한다. 매일 알림은 11월 8일부터 12월 5일까지 오후 9시 한국시간으로 설정한다.
