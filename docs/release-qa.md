## 출시 전에 남은 결함과 검증

### P1 — Android 위젯 대기 입력 날짜 누락 (알려진 결함)

`targets/HabitWidgetAndroid/kotlin/HabitWidgetProvider.kt`의 `queuePendingToggle`은 habitId 문자열만 저장한다. `src/utils/widgetData.ts`의 `processPendingWidgetToggles`는 앱 재개 시 이를 현재 날짜의 toggle로 처리한다. 따라서 전날 위젯에서 누르고 다음 날 앱을 열면 오늘 기록이 변할 수 있다. OS에서 직접 재현하지는 않았으나 생산자/소비자 코드에서 날짜 누락을 확인했다.

수정 방향: 이벤트에 날짜와 최종 완료 상태를 저장하고, 중복 재처리에 안전한 적용 및 원자적 큐 소비를 구현한다. 기존 날짜 없는 큐의 업그레이드 처리도 필요하다. 자정·여러 번 탭·앱 강제 종료·빠른 포그라운드 전환을 실제 Android에서 검증하기 전에는 위젯 포함 버전을 출시하지 않는다.

### 네이티브 검증 대기

- 실제 결제/취소/실패/구매 복원/재설치/환불 후 권한 반영 (스토어 sandbox).
- 알림 허용/거부/OS 예약 실패/체크 취소/시간대 이동. 현재 7일 예약창이므로 7일 이상 앱을 열지 않았을 때 이후 알림이 끊기는 동작도 제품 결정과 검증 필요.
- 위젯 데이터 동기화·졸업 반영·기존 정원 UI와 새 본문 UI의 일관성.
- 작은 기기 키보드, 큰 글자, VoiceOver/TalkBack, 안전 영역과 뒤로 가기.
- 실제 네이티브 화면으로 스토어 캡처 교체 및 App Store Connect/Play Console 업로드.
- 기존 문서에 기록된 의존성 보안 경고와 Expo SDK 업그레이드 검토는 별도 남아 있다. 이번 작업에서 전부 해결했다고 주장하지 않는다.
